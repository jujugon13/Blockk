## 의존

| 대상 | 경유 | 비고 |
|---|---|---|
| 관계형 DB·색인 큐 | 생성자에 주입된 백엔드 계약 | DB 드라이버 직접 사용 없음 |
| 단일 작업 실행 | 생성자에 주입된 콜백 | 색인 구현을 직접 import하지 않음 |

## 이 폴더가 책임지지 않는 것

- 작업 상태 전이, 임베딩 생성과 벡터 저장
- REST 응답 봉투와 관리자 노드 목록 API
- 종료 유예를 넘긴 Python 실행 스레드의 강제 중단
