# 임베딩

검색 질의 임베딩의 재시도·회로 차단과 문서 색인용 결정적 배치를 제공한다.

## 담당 명세

| 명세 절 | 내용 |
|---|---|
| `specs/14-search-and-rag.md` S3.1 | 벡터 검색에 전달할 질의 임베딩 |
| `specs/14-search-and-rag.md` S13 | 외부 호출 재시도, 입력 절단, 회로 차단 |

## 담당 acceptance criteria

| ID | 요약 | 검증 수준 | 테스트 |
|---|---|---|---|
| AC-RS-23 | 연속 5회 실패 뒤 6번째 호출을 전송 없이 차단 | 모의 | `AC_RS_23` |

## 의존

| 대상 | 경유 | 비고 |
|---|---|---|
| 외부 임베딩 API | 주입된 `EmbeddingTransport` | HTTP 클라이언트와 공급자별 토큰 절단기는 어댑터 책임 |

## 이 폴더가 책임지지 않는 것

- 검색 파이프라인 순서와 오류 응답 봉투
- 색인 소유권 검증과 벡터 저장 트랜잭션
- 공급자별 HTTP·토크나이저 구현
