## 의존

| 대상 | 경유 | 비고 |
|---|---|---|
| 관계형 키 원장 | `shared.McpTokenStore` | 원본 키는 저장 계약에 포함되지 않음 |
| 검색·문서·권한 조회 | `shared.McpToolBackend` | 도구는 읽기 전용 |

## 이 폴더가 책임지지 않는 것

- 웹 JWT 발급과 검증
- 검색 파이프라인 및 문서 색인의 내부 구현
- 다중 인스턴스 사이 호출 카운터 공유
