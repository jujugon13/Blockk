## 의존

| 대상 | 경유 | 비고 |
|---|---|---|
| 외부 생성·심판 API | `shared.LanguageModel` 또는 생성자에 주입된 callable | 공급자 SDK·HTTP를 직접 사용하지 않음; LLM 심판은 총 4회 시도 |
| 검색 파이프라인 | 컨텍스트에 주입되는 `GuardrailService` 포트 | 단계 순서·조건·추적 이름을 알지 않음 |

S5·S6의 실제 패턴 목록이 팩에 없으므로 `IMPLEMENTATION_DECISIONS.md`에 따라 생성자 주입을 허용하고,
기본값은 보수적인 참조 목록만 제공한다.

## 이 폴더가 책임지지 않는 것

- 검색 단계 순서, 활성 조건, 추적 이름과 HTTP 오류 봉투
- 외부 API 인증·전송·재시도
- 검색·생성 캐시와 권한 필터
