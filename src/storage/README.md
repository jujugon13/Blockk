# 파일 저장소

설정으로 선택된 하나의 저장소에 원본 파일을 기록·조회하고 미사용 후보 객체를 정리한다.

## 담당 명세

| 명세 절 | 내용 |
|---|---|
| `specs/01-purpose-and-boundary.md` §1 FR-SYS-005 | 활성 저장소 선택과 위치 일치 규칙 |
| `specs/09-recovery-and-side-effects.md` §16.2 | 객체 부작용과 어댑터별 동작 |

## 의존

| 대상 | 경유 | 비고 |
|---|---|---|
| 파일 시스템 | `shared.ObjectStorage` | 로컬 어댑터가 원자 교체 사용 |
| 오브젝트 스토리지 | `shared.ObjectClient` | 실행 환경이 실제 클라이언트를 주입 |

## 호환성 동작

- Q-20: 기존 파일 객체는 제공자와 네임스페이스가 현재 활성 설정과 다르면 재사용하지 않고 오류로 처리한다.
- 문서 또는 컬렉션 삭제는 원본 객체를 삭제하지 않는다.

## 이 폴더가 책임지지 않는 것

- `(해시, 크기)` 파일 객체 원장과 전역 중복 조회
- 문서·버전 트랜잭션과 동시 업로드 경쟁 판정
- 파일 형식 검증과 파싱
